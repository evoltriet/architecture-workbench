# AI-Assisted Architecture Prompt Pack

These prompts support facilitated architecture work with any capable language model. They do not
grant an AI approval authority, and the CLI never sends document content to a model.

## Safe Use

- Remove secrets, personal data, customer data, credentials, internal hostnames, and confidential
  commercial information before using an external model.
- State what sources the model may use and require it to distinguish evidence from inference.
- Treat generated diagrams, calculations, controls, and citations as unverified until reviewed.
- Keep consequential decisions and approvals attributable to people.

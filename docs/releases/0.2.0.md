# Architecture Workbench 0.2.0

Architecture Workbench is now an agent-ready architecture-as-code framework for humans and LLM
agents to collaboratively discover, design, review, and publish software architectures.

## Highlights

- Project-level `AGENTS.md`, optional agent edit policy, approval gates, and lifecycle status
- Structured `REQ`, `ASM`, `ADR`, `RSK`, and `EVD` records with traceability validation
- Deterministic JSON context, status, prompts, change-policy, diagram, review, and build contracts
- Local stdio MCP tools, resources, and prompts built on the stable `2026-07-28` SDK
- Canonical draw.io formatting plus semantic graph inspection and validation
- Human approval safeguards, project path confinement, and prompt-injection guidance
- Windows and Ubuntu tests, deterministic evaluations, package verification, and DOCX visual QA

This release does not publish to npm and does not add model credentials, telemetry, direct model
calls, external publication, or provider-specific integrations.
